Windows 安装提示

  1. 运行下载的安装包,按提示选择安装位置。
  2. 安装包暂未做代码签名,如果出现「Windows 已保护你的电脑」,点「更多信息」→「仍要运行」。
  3. 首次打开后,在 设置 → 模型配置 里登录官方账号,或添加你自己的模型服务。

macOS 安装提示

  1. 不确定是哪种芯片:点屏幕左上角苹果菜单 →「关于本机」,「芯片」一栏写着 Apple M… 就选 Apple 芯片版,写着 Intel 就选 Intel 版。
  2. 打开下载的 .dmg,把 MarioCode 拖进「应用程序」文件夹。
  3. 安装包暂未经过苹果公证,第一次打开会被拦下:打开「系统设置 → 隐私与安全性」,在页面下方点「仍要打开」。
  4. 如果提示「已损坏,无法打开」,在「终端」里运行 xattr -dr com.apple.quarantine /Applications/MarioCode.app,再重新打开。
  5. macOS 版暂不支持应用内自动更新:有新版本时应用会提示你,回到本页下载新的 .dmg 覆盖安装即可,数据不会丢。

常见问题

MarioCode 收费吗?

免费,MIT 开源。模型调用按你使用的模型服务计费,由服务商收取。

需要准备什么?

一个可用的模型来源:Claude 或 Codex 官方账号,或者任意兼容 OpenAI / Anthropic 协议的 API 服务。

我的代码和对话会被上传吗?

会话和配置保存在你自己的电脑上,MarioCode 不收集使用数据。对话内容只会发送给你配置的模型服务。

怎么更新?

应用会自动检查新版本。Windows 版有更新时会提示你下载并重启安装;macOS 版会提示你回本页下载。也可以随时回来下载最新安装包覆盖安装。

有 macOS 版吗?

有,分 Apple 芯片和 Intel 两个版本。安装包暂未经过苹果公证,第一次打开需要在「隐私与安全性」里允许;也暂不支持应用内自动更新,有新版本时回本页下载即可。
