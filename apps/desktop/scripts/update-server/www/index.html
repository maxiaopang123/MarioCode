安装时可能看到的提示

Windows

  1. 运行安装包,按提示选择安装位置。
  2. 安装包暂未签名。若出现「Windows 已保护你的电脑」,点「更多信息」→「仍要运行」。
  3. 首次打开后,在 设置 → 模型配置 里登录,或添加你自己的模型服务。

macOS

  1. 打开 .dmg,把 MarioCode 拖进「应用程序」。
  2. 暂未公证。第一次打开到「系统设置 → 隐私与安全性」,点下方「仍要打开」。
  3. 若提示已损坏,在终端运行 xattr -dr com.apple.quarantine /Applications/MarioCode.app 后再打开。
  4. macOS 暂不能在应用内更新。有新版本时回到本页,覆盖安装即可,数据不会丢。

常见问题

收费吗?

客户端免费,MIT 开源。模型调用由你使用的服务商计费。

需要准备什么?

最快的方式:内置中转站,粘贴 Key 即用 22 个模型。也可以用 Claude 或 Codex 账号,或任意兼容 OpenAI / Anthropic 协议的 API。

代码和对话会上传吗?

会话和配置在你自己的电脑上。MarioCode 不收集使用数据,对话只发给你配置的模型服务。

怎么更新?

应用会自己检查。Windows 提示下载并在重启时安装;macOS 提示回本页下载。也可以随时覆盖安装最新包。
