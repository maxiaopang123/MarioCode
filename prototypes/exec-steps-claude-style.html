改了什么

  1. 分组标题：机械计数 → 一句话。「13 个操作　Grep ×2 · Glob ×1 · Bash ×3 · Read ×7」→「搜索代码、执行 3 条命令、读取 7 个文件」。
  2. 组内一行：工具名 + 原始参数 → 一句人话。原始参数降级到展开层。
  3. 展开层按工具排版，不再倒 JSON。Bash 是 $ 命令 + 输出 + 退出码；Read 是内容；Edit/Write 是 diff。不再有「输入 / 结果」两个大写标签。
  4. 减噪与结构：去掉工具图标与成功状态点（只有失败出红点），右侧统一 +N −N，组内行装进描边容器、发丝线分隔。
两个要你定的点：
① 那些人话从哪来。A 规则映射（Grep →「搜索 X」），零成本、本地算得出，但说不出「找到了什么」；B 让模型在 tool_use 里自带 description（Claude 就是这么做的），多一点 token，语义最准。建议先 A 后 B。
② 动词语言。Read / Edit / Write（跟 Claude 一致）还是 读取 / 编辑 / 写入（全中文）。
