设计规范 · V4

V4 = V3 的通用性重构:布局结构、组件职责、状态来源与 IPC 全部不变,只换视觉层。基底为纯黑白中性色,主题色只用于状态与主操作,状态色(成功 / 警告 / 失败 / 计划)独立于主题色。

主题色的职责边界

主题色只出现在:当前选中(会话 / 文件 / Tab 下划线)、焦点环、进度、链接、主操作按钮。不再用于整体背景、边框、代码高亮或大面积填充。选中行用浅灰 --active,图标与文字不再染色,界面回到内容优先。
